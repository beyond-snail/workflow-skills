## 五、关系汇总

```
核心实体表 (biz_xxx)
├── 记录核心业务对象当前状态
│   ├── status            当前状态
│   ├── owner_id          所属用户或主体
│   └── updated_at        更新时间
│
└── 根据业务操作写入或更新

业务明细表 (biz_xxx_detail)
└── 记录每次业务操作明细
    └── 支持追溯和问题排查

统计记录表 (biz_xxx_stat)
└── 记录统计、聚合或衍生结果
    ├── 支持追溯
    ├── 支持重算
    └── 支持验收核对
```
