# 轻量模式说明

## 适用场景

仅适用于以下类型的需求：

1. 小 bugfix
2. 小范围逻辑修正
3. 单任务、低歧义、无复杂阶段切换的需求

若涉及以下任一项，退出轻量模式，回到完整模式：

1. 新增或调整数据库结构
2. 多阶段交付
3. 业务语义仍有歧义
4. 需要产品确认清单或复杂流程图对齐

## 轻量模式最小交付

可以简化为：

1. `需求池` 补一条或补一段状态说明
2. `任务看板` 至少补一条任务
3. 在以下两者中至少保留一份可追溯文档：
   - `开发任务拆解`
   - `PRD追溯`
4. 若验证口径有变化，至少补一份测试或联调记录

## 可以省略的内容

在确认属于轻量模式后，可以不强制补：

1. 完整的物理表设计
2. 产品确认清单
3. 流程图与实现对齐说明
4. HTML 总览页
5. 非必要 SQL 模板

## 不能省略的内容

以下原则在轻量模式下仍然必须保留：

1. `PRD` 基线不能省
2. 状态管理不能省
3. 至少一份可追溯证据不能省
4. 人工审核门不能省
5. 不得在 requirement 侧直接进入 execution
