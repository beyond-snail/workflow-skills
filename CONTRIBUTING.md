# Contributing

Thanks for your interest in contributing to `workflow-skills`.

## Ways to contribute

1. Open an issue for bugs, docs gaps, or feature ideas.
2. Open a pull request for fixes, improvements, or new templates/scripts.
3. Help improve examples and migration guides for different host environments.

## Development flow

1. Fork this repository and create a feature branch.
2. Keep changes focused and easy to review.
3. Update docs when behavior or commands change.
4. Run relevant checks/tests locally when available.
5. Submit a PR with clear context.

## Pull request checklist

- Scope is clear and limited.
- Motivation and expected impact are explained.
- Validation steps are provided (commands, outputs, screenshots if needed).
- Related docs are updated.

## Commit message suggestion

Use concise prefixes such as:

- `docs:` documentation updates
- `feat:` new capabilities
- `fix:` bug fixes
- `refactor:` internal improvements

## Code of conduct

Please keep discussions respectful and constructive.
